# Nigeria Vaccination Coverage Analysis (2018)

## Project Overview
This project uses Microsoft Power BI to analyze vaccination coverage data across Nigerian states in 2018. The dashboard presents key coverage statistics and enables users to explore the data by vaccine type.

## Project Objectives
- Summarize vaccination coverage using key performance indicators.
- Compare vaccination coverage across states.
- Present the findings through an interactive dashboard.
- Highlight areas that may require further investigation.

## Tools Used
- Microsoft Power BI
- Power Query, where applicable, for data preparation

## Dashboard Features
- Average vaccination coverage
- Maximum and minimum coverage
- Top 10 states by average vaccination coverage in the displayed view
- Interactive vaccine-type slicer
- Key insights based on the dataset

## Key Findings
- Average vaccination coverage: 68.46%
- Maximum recorded coverage: 99.90%
- Minimum recorded coverage: 12.00%

The results show variation in vaccination coverage within the dataset. Further analysis could investigate states with lower recorded coverage.

## Limitations
The analysis uses 2018 data and does not represent current vaccination coverage. Findings are limited to the data available in the dataset.

## Conclusion
This project demonstrates how Power BI can be used to summarize public health data, compare vaccination coverage, and communicate findings through visualizations.
